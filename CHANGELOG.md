# Changelog

## 0.3.0, unreleased

Install and restart to get the companion immediately. No project config is
required. Check project and `/ernesto check` run a detected existing package
check through the host process API only on explicit user action. Detection
supports npm, pnpm, yarn and bun scripts, with no dependency downloads.
Command completion, failure and input freshness remain separate from verified
test evidence; no test counts or coverage are invented. Bounded output stays
in session memory behind Details. Off/hide/workspace changes discard late
results. The optional exact Vitest integration and existing config remain
compatible; its explicit fallback initializes missing defaults internally.
Setup/doctor show concise readiness instead of manual cache-path instructions.

## 0.2.0, source main, no tagged release

Guided `/ernesto setup` and `/ernesto doctor`; QA observation on by default;
workspace on/off preferences retained across sessions; automatic connection to
newly created config; explicit helper `--setup` and `--init` modes that generate
conventional defaults without overwriting existing config. Runtime hooks remain
read-only and never run tests. Existing QA aliases and strict evidence checks
remain supported. The companion gains compact terminal pixel art, a steady
portrait during routine comparisons and a structured evidence pane with test
counts, next steps and an expandable scope/record section. Narrow layouts keep
controls and evidence ahead of decoration. This is a development candidate,
not a published release. Bundled sarcastic banter now rotates on activity,
with playful jabs and a quiet switch that also covers chocolate replies;
redraws and snapshot polling do not select new jokes. A new 46-second actual CLI
demo, poster, seven screenshots and four caption/transcript languages show the
candidate setup, UI and personality; the earlier tagged release stays unchanged.

## 0.1.0, 14 October 2026

Initial stable version of the companion and optional scoped Vitest evidence.
Version metadata and displayed help now identify 0.1.0. Failed CI preserves its
failing status and uploads only a bounded sanitized status receipt for seven days.
See the versioned release record for exact checks, source and artifact digests.

## 0.1.0-rc.1, 14 October 2026

Companion band, owner-approved master artwork and terminal-native poses;
quiet/hide/reduced-motion/chocolate commands; optional reviewed project QA;
explicit Vitest 4.1.11 helper, strict records, working-tree snapshots,
conservative outcome/freshness/completeness, and an on-demand evidence pane.

The immutable prerelease remains available with its original tagged source and
artifacts. Its public installation checks are documented in the release record.
Anthropic directory submission remains separate; no listing is claimed.
